RS Rabby.com — প্রেমের ওয়েবসাইট

ফাইল:
- index.html = মূল ওয়েবসাইট
- style.css = ডিজাইন
- script.js = বাটনের ইন্টার‌্যাকশন

অনলাইনে দেওয়ার সহজ উপায়:
1. এই ZIP খুলে ফাইলগুলো বের করুন।
2. GitHub-এ একটি নতুন repository তৈরি করুন (যেমন rsrabby).
3. index.html, style.css, script.js আপলোড করুন।
4. Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. GitHub যে Pages link দেবে সেটি দিয়ে ওয়েবসাইট খুলবে।
6. পরে চাইলে rsrabby.com domain কিনে GitHub Pages-এর Custom domain-এ সেট করতে পারবেন।

নোট: নিজের ছবি বসাতে চাইলে ছবির নাম photo.jpg করে index.html-এ যোগ করা যাবে।
